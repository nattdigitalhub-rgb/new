YouTube search key

This key stays on this phone. It is never sent anywhere except to YouTube.

How to get a free key

  1. Open Google Cloud and sign in with any Google account. Create a project (any name, like "Wavelet").
  2. Open the YouTube Data API v3 page and tap Enable.
  3. Go to Credentials, tap Create credentials, then API key. Copy the key.
  4. Paste it above and tap Save key.

It's free with no card needed. The free allowance covers about 100 searches a day. Playing songs doesn't use it up.

Back up your library

Your liked songs and playlists are saved on this phone only. Copy a backup to keep them safe or move them to another phone.

Paste a backup above, then tap Restore.

Wavelet plays music through YouTube's official player, so YouTube ads may appear and music may stop when your screen locks.
